# DaB (Design and Build)

**Minecraft 1.21.1 · NeoForge** 건축·조경 설계 모드.
도면 테이블의 쿼터뷰 편집창에서 마을이나 큰 건축물을 먼저 설계하고, 월드에 투영된 설계를 단계별로 따라 지어요.

> Design villages and large builds on a blueprint table in a quarter-view editor, then build them in the world step by step: demolition, floors, paths, then structures in your chosen order.

현재 버전: **0.2.15** (개발 중, 공개 전)

**셰이더 팩(Iris/Oculus)은 지원하지 않아요.** 셰이더를 켜면 편집창 음영이 사라지고 월드 투영이 깨져요. 셰이더가 켜져 있으면 편집창을 열기 전에 경고창이 뜨니, 설계·건설 중에는 꺼 주세요.

## 빌드

```
gradlew.bat build        # Windows
./gradlew build          # macOS / Linux
```

결과물은 `build/libs/` 에 생겨요.

## 사용 흐름

1. **도면 테이블**을 설치해요. 옆으로 2칸 × 위로 2칸을 차지하는 제도대이고, 설치한 칸의 청크가 설계 영역의 기준 청크가 돼요.
2. **빈 청크 도면**을 테이블에 올리고 **설계 시작**을 누르면, 테이블 주변 3×3 청크가 그 도면의 설계 영역이 돼요. 영역은 편집창에서 넓히거나 줄일 수 있어요.
3. 테이블에서 **편집창**을 열어 설계해요. 여러 사람이 같은 도면을 동시에 편집할 수 있어요.
4. 설계가 정해진 **청크 도면**을 손(주손 또는 보조손)에 들면 **월드에 투영**돼요.
5. 투영을 따라 단계별로 지어요: **철거 → 바닥 → 길 → 구조물(정한 순서대로)**.

### 설계 영역

- 청크 단위이고, 도면 하나에 최대 100청크까지 넓힐 수 있어요.
- 영역은 항상 기준 청크와 이어진 한 덩어리여야 해요.

## 편집창

쿼터뷰 시점의 설계 화면이에요. 실제 월드 지형을 스냅샷으로 받아 그 위에 설계를 덮어 보여 줘요.

**시점 큐브:** 뷰포트 오른쪽 위의 큐브에서 면·모서리·꼭짓점을 누르면 그쪽에서 보는 시점으로 바뀌어요. 윗면은 평면도, 옆면과 세로 모서리는 정면도(0°), 위 모서리는 45°, 위 꼭짓점은 기본 쿼터뷰(30°)예요. 아래쪽 절반은 쓰지 않아요. 큐브 아래 버튼으로 90° 회전과 기본 시점(북동 30°) 복귀를 할 수 있어요. 정면 시점에서는 화면 이동·칠하기·구조물 이동이 카메라와 마주 보는 세로 평면을 기준으로 동작해요.

### 도구

| 키 | 도구 | 하는 일 |
|---|---|---|
| `B` | 직접조작 | 설치 / 채우기 / 대체 / 지우기 (`1` `2` `3` `4`) |
| `P` | 배치 | 라이브러리의 구조물 조각을 놓기 |
| `V` | 선택 | 놓은 구조물 선택 · 이동 · 회전 · 반전 · 저장 |

- **직접조작:** 상자·원기둥·구 모양 범위로 칸을 다뤄요. 기준점은 "블록 밖에 / 블록에 / 가운데" 중에서 골라요. 재료는 3칸까지 넣고, 가중치와 랜덤 %로 섞어 놓을 수 있어요.
- **태그:** 칸마다 바닥 / 길 / 구조물 태그를 붙여요. 태그에 따라 월드에서 지을 단계가 정해져요.
- **설치 미리보기:** 놓을 블록의 방향과 붙일 면을 골라요. 육면체의 뒤쪽 면(아랫면 등)은 점선으로 비쳐 보이고, 고른 면이 뒤쪽이면 옅게 채워져요. 뒤쪽 면은 "반대면" 버튼으로 골라요. 천장에 매다는 랜턴은 붙일 면을 아랫면으로 정해요.
- **배치:** 구조물 조각을 "블록 밖에"(기본)나 "블록에"로 놓아요. "블록에"는 조각의 맨 아래 층을 가리킨 블록의 층에 겹쳐 놓는 방식이라, 바닥이 달린 구조물에 써요. 겹친 바닥·길 칸은 그 구조물이 대체해요.
- **배치 방식:** 배치 도구에서도 1~4로 설치 / 채우기 / 대체 / 지우기를 골라요. 설치는 조각 전체를 새 구조물로 놓고, 나머지는 조각의 공기 아닌 칸만 써요(채우기 = 빈 칸에만, 대체 = 블록이 있는 칸에만, 지우기 = 조각 모양대로 지움).
- **구조물 편집:** 구조물을 선택하고 직접조작(B)으로 고치는 동안에는 그 구조물만 보여요.
- **단면:** 단면(L)을 켜고 Y·X·Z 축 버튼을 누르면 축마다 슬라이더가 열려 깊이를 따로 정해요. 여러 축을 동시에 자를 수 있어요.

### 라이브러리

- **출처:** 바닐라·모드의 구조물, 월드의 구조물 폴더, 내 폴더(기본 `<게임 폴더>/designandbuild/structures`)에서 조각을 불러와요.
- **고르기:** 출처 / 종류 / 지형 태그로 걸러요. 같은 축 안에서는 합집합, 다른 축끼리는 교집합으로 걸러요.
- **숨기기:** 쓸모없는 구조물이나 태그를 숨길 수 있어요. 숨김 목록은 `config/designandbuild/hidden/` 으로 내보내거나 불러와 다른 사람과 나눌 수 있어요.
- **저장:** 편집창에서 만든 구조물을 저장해 다시 쓸 수 있어요.

## 월드 투영과 건설

설계가 정해진 도면을 손에 들면, 지금 보는 단계의 설계가 월드에 반투명하게 겹쳐 보여요.

### 단계

| 단계 | 내용 |
|---|---|
| 철거 | 설계와 다른 기존 블록을 치우기 (빨간 표시, 액체 원천은 메우기 표시) |
| 바닥 | 바닥 태그 칸 |
| 길 | 길 태그 칸 |
| 구조물 | 구조물마다 하나씩, 정한 순서대로 |

- 철거는 위층부터, 나머지는 아래층부터 진행해요. 한 층을 끝내면 다음 층으로, 한 단계를 끝내면 다음 단계로 자동으로 넘어가요.
- 층 표시는 도면 메뉴(도면을 들고 허공에 우클릭)에서 골라요: **이 층만 / 이 층까지 / 단계 전체**.

### 표시

| 표시 | 뜻 |
|---|---|
| 반투명 블록 | 놓아야 할 블록 |
| 빨간 상자 | 철거할 블록 |
| 파란 상자 | 메울 액체 원천 |
| 주황 외곽선 | 같은 블록인데 방향 등이 다름 |
| 청록 외곽선 | 도구로 가공하면 되는 블록 |

### 가공

있는 블록을 도구로 가공하면 목표가 되는 칸은 철거 대상이 아니에요. 그 칸의 단계에서 가공 칸으로 표시돼요.

- 삽: 잔디·흙 등 → 흙길
- 괭이: 잔디·흙·흙길 → 경작지, 거친 흙·뿌리 흙 → 흙
- 도끼: 원목 껍질 벗기기, 구리 녹 긁기, 밀랍 벗기기
- 꿀벌집: 구리 밀랍 칠

여러 번 거쳐야 하는 가공도 찾아요(최대 4회. 예: 산화된 구리 → 구리 = 도끼 3회). NeoForge의 도구 가공 경로로 판정하므로 다른 모드 블록의 가공도 따라와요. 그리고 흙과 잔디 블록은 서로 완료로 쳐요. 흙을 놓으면 잔디가 번지기 때문이에요.

### 재료 목록

- 화면 오른쪽 위에 현재 층이나 현재 단계에 남은 재료가 떠요. 가공할 칸은 재료 대신 도구 줄(사용 횟수)로 보여요.
- `N` 키로 접힘 → 현재 층 → 현재 단계 순으로 바꿔요.

### 키 (기본값, 조작 설정에서 바꿀 수 있음)

| 키 | 동작 |
|---|---|
| `↑` / `↓` | 층 이동 |
| `←` / `→` | 단계 이동 |
| `N` | 재료 목록 펼침 방식 |

### 건설망치

보조손에 도면, 주손에 망치를 들고 투영 칸을 우클릭하면 인벤토리의 블록을 꺼내 설계대로 놓아요.

- 웅크리고 우클릭하면 이어진 칸을 한꺼번에(최대 512칸) 놓아요.
- 지금 보는 단계와 층의 칸만 놓을 수 있어요.
- 철거와 가공은 하지 않아요.

### 즉시 반영

명령어 권한 2 이상이면 도면 메뉴에서 한 단계를 월드에 바로 반영할 수 있어요. 아이템은 쓰지 않아요. 도면마다 마지막 1회는 되돌릴 수 있어요.

| 아이템 | 재료 |
|---|---|
